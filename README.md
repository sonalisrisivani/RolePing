# Role Ping

An early job discovery app for users seeking roles. The current frontend has a simple local preview, Supabase email sign-in, and private profile settings. Job collection and notifications are not built yet.

## Run

```bash
cd app
npm ci
npm run dev
```

Open the URL printed by Vite, usually [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Without Supabase credentials, settings save only in this browser.
